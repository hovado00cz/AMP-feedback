## 🇨🇿 Zpětná vazba

Tento repozitář slouží k **hlášení chyb a návrhům nových funkcí** programu Amiga Media Player. Zdrojové kódy AMP zde nejsou zveřejněné.

**[Nahlásit chybu nebo navrhnout funkci](../../issues/new/choose)**

Před odesláním prosím zkontroluj [existující hlášení](../../issues), jestli už někdo stejný problém neřešil.

### Co uvést při hlášení chyby

- Verzi AMP, například **1.1**.
- Sestavu: model Amigy, PiStorm / Emu68, CM4 / Pi 4, AmigaOS a případně RTG / AHI.
- Co jsi udělal, co se stalo a co jsi očekával.
- Pokud můžeš, přilož screenshot nebo krátký postup k zopakování chyby.

Při návrhu nové funkce stačí popsat, co bys chtěl přidat a k čemu by to bylo užitečné.

**Upozornění:** Nevkládej sem hesla, soukromé údaje ani neveřejné soubory. Hlášení jsou veřejná. Na všechny návrhy nemusí být možné reagovat nebo je realizovat.

## 🇬🇧 Feedback

This repository is for **bug reports and feature requests** for Amiga Media Player. The AMP source code is not published here.

**[Report a bug or request a feature](../../issues/new/choose)**

Please check [existing issues](../../issues) before opening a new one.

### What to include in a bug report

- AMP version, for example **1.1**.
- Your setup: Amiga model, PiStorm / Emu68, CM4 / Pi 4, AmigaOS and relevant RTG / AHI details.
- Steps to reproduce the problem, what happened and what you expected.
- A screenshot, when helpful.

For feature requests, describe what you would like AMP to do and why it would be useful.

**Please note:** Do not post passwords, private information or non-public files. Issues are public. Not every request can be implemented or answered.
